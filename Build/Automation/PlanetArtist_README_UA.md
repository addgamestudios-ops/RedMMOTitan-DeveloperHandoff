# RED MMO — художня копія поверхні планети

Цей окремий проект призначений лише для художника середовища. Він містить 50-км планету, 27 плоских авторських наборів карт, злиті макрограні, потрібні залежності рівня та закріплену копію PlanetGen. Steam, PvP, HUD, інвентар, кораблі та повний ігровий клієнт не є частиною завдання художника.

## Запуск

1. Розпакуйте ZIP у короткий шлях, наприклад `D:\RED_Mars_Artist`.
2. Переконайтеся, що встановлено Unreal Engine 5.8.
3. Запустіть `OPEN_PLANET_EDITOR_SAFE.cmd` (DX11 і локальний DDC без Zen).
4. Відкрийте карту `/Game/RedMMO/Maps/RedPlanetGen_50km_ArtistCanvas`.
5. Це content-only проєкт: компіляція RedMMO або Visual Studio не потрібні.

## Де працювати

- Вхідні карти: `SourceArt/Planet50Km/AuthoringPatches`.
- Злиті шість граней: `SourceArt/Planet50Km/MacroFacesFromPatches`.
- Скрипт: `Tools/generate_planet_authoring_patches.py`.
- Повний посібник: `Documents/RED_Mars_27_Patches_Artist_Guide_UA.pdf`.

Перед кожною зміною зробіть `snapshot-sources`. Редагуйте лише п'ять канонічних файлів потрібної ділянки. Потім виконайте `accept-edits` та `bake-existing`. Не використовуйте `initialize-blockout --force-overwrite-existing-sources` для звичайної роботи: ця команда перегенерує всі 27 джерел.

## Художній напрям

Це Марс на ранній стадії людського та чужопланетного тераформування. Два гігантські орбітальні лазери б'ють у кригу північного та південного полюсів. Тала вода створює полярні моря, океанічні басейни, річки, каньйони, озера й дельти, що проходять крізь червону марсіанську пустелю. Планета повинна все ще впізнаватися як Марс; вода, життя та мегаструктури показують незавершений процес перетворення.

## Що повернути команді

- Змінені файли відповідних `RED_Patch_XX`.
- Нові меші, матеріали й текстури з чіткими назвами та без зайвих залежностей.
- Список змінених ділянок і короткий опис композиції.
- Скріншоти з поверхні, польоту та орбіти.
